# V1.0.7 / 39 候选说明

本次沿正式 V1.0.6 / 38 开发，包名与正式签名保持；未正式发布，等待用户界面、账号关联及真实设备验收。不得替换 V1.0.6 APK 或提前修改更新发行记录。

## 欢迎页纠偏

欢迎页恢复既有布局，没有统计或学校同步勾选项、附加说明、“了解详情”或占位高度。基础政策“同意并继续”只更新基础政策版本，不开启可选数据处理。两个可选控制位于隐私政策底部二级页面；旧同意、拒绝、撤回与安装标识保留。不恢复自动统计弹窗。

## 修改范围

- Material3 接入既有蓝白颜色；检查更新使用圆角浅蓝实体按钮；欢迎政策链接为品牌蓝。
- 隐私政策、个人信息清单离线可读，说明手机本地加密学校凭据与可选上传学校标识的区别。
- 学校同步仅在可选同意后发送学校、字符串学号、状态、来源、必要时间。校验在客户端完成，后端同时校验安装凭证和当前平台注册会话，绝不发送学校密码、Cookie、验证码、令牌、课表和成绩。
- 当前账号与排队事件绑定，切换账号不会发送上一账号的学号。解绑/撤回使用幂等回执；关闭清理待发资料，离线撤回在前台重试。
- 前台事件按北京时间日期节流，补发昨日事件后继续记录今天；协议 3 保存事件时账号，登录或版本变化不生成新安装。
- 学校绑定为原生 View，局部 autofilledHighlight 使用极淡蓝圆角；保留密码管理器、提示、粘贴和显隐功能。

## 已执行验证与限制

单元测试、隔离后端 HTTP 联调与 API 36 模拟器仪器测试已执行。欢迎视觉测试确认不存在新选项，并原生渲染 1200×2664 截图。基础同意不改变四种历史统计选择；安装并发身份稳定；学校同步、账号切换、撤回均在合成账号验证。

模拟器 V1.0.6 → V1.0.7 使用 install -r 覆盖升级，事前保存可读取的应用数据备份，升级前后安装身份文件哈希相同。没有卸载或清除用户数据。
