# 我的长理隐私政策（发布前草案）

> 状态：DRAFT。本文依据 Android 客户端提交 `5e788edefd92b0301fa5f07dc733bce72333e813` 及发布前整改源码编写，不是最终法律文本。运营主体联系方式、生产域名、服务器位置、服务端保存期限、备份与日志删除策略均待生产后端审计确认。

## 1. 应用身份

本应用由个人开发者独立开发，是面向校园生活场景的非官方辅助工具，与长沙理工大学不存在官方隶属或授权关系。

## 2. 首次启动与同意

首次安装会在非必要联网和个人信息处理前展示身份与隐私说明。客户端使用整数 `privacyConsentVersion` 记录同意版本；重大政策变化可提升版本并重新提示。暂不同意时，不启动远程配置、版本检查、自有账号恢复、高德隐私状态同步等非必要流程，也不申请定位、相机、图片或通知权限。用户可查看本地草案、重新选择或退出。

## 3. 三类数据流必须区分

### A. 发送至“我的长理”自有后端

- 自有账号：手机号、账号密码、昵称、服务端用户 ID、客户端随机生成的 `installationId`。
- 体育预约：用户主动填写的姓名、学号，以及场馆、日期、时段、场地和预约资料快照。
- 失物招领：物品类型、名称、分类、地点、日期/时间、描述、认领说明及用户主动上传的图片。
- 用户反馈和资源投诉：分类、标题、正文、原因、详情、App 版本及账号关联信息。

当前 Release 自有服务仍是 `.invalid` 安全占位，未部署生产后端。上述服务端数据保存期限、服务器位置、备份、日志、访问控制和删除完整性：**待生产后端审计确认**。

### B. 直接发送给学校或外部服务

- 学校统一身份认证/教务/MOOC：学号、教务密码、验证码、Cookie/session、查询条件；学校返回课表、成绩、考试、MOOC 等结果。
- 校园卡/电量等学校服务：宿舍楼、房间或查询所需参数。
- 高德相关服务：用户进入校园地图并单独同意后，可能处理粗略/精确位置、IP、设备和网络信息；具体字段待取得 `Lite3DMap.jar` 可审计版本后复核。
- 外部 Web 页面：四六级、普通话、学校官网/图书馆、GitHub 等目标页面会获得 IP、浏览器标识及用户主动填写的数据。

根据当前可审计客户端逻辑，学校教务账号、教务密码、验证码和学校 Cookie/session **不会发送至“我的长理”自有后端**。该结论受缺失的 `CSUSTDataGet` AAR 和 `Lite3DMap.jar` 限制，正式成品仍需抓包验证。

### C. 只在设备本地处理或缓存

- 学号；使用 Android Keystore AES-GCM 加密保存的教务密码。
- 加密保存的 MOOC Cookie；内存中的学校会话及 WebView Cookie。
- Room 数据库中的课表、课程、教室、教师、周次、学期和 studentId。
- MMKV 中的成绩、考试、MOOC、学校头像/用户名、宿舍/房间/电量和小组件缓存。
- 自有登录 token 使用 Android Keystore 加密保存；用户信息 JSON 的部分字段不是全量加密。
- 图片在选择、拍摄、裁剪时可先在设备本地处理；用户确认发布或上传后才发送至相应目标服务。

## 4. 权限

- 定位：只在校园地图用户明确同意后申请，用于地图定位。
- 相机：用户主动拍照发布或 WebView 文件上传时申请。
- 图片/旧存储：用户主动选择图片时使用；当前是否可全面迁移 Photo Picker 待完整依赖回归。
- 通知：用户开启课程提醒等功能时申请。
- 精确闹钟：用户主动配置精确课程提醒时进入系统授权。
- 网络、网络状态、开机恢复、前台服务等权限的详细清单见 `PERSONAL_INFORMATION_LIST_DRAFT.md`；本地 SDK 缺失导致 merged manifest 尚不能最终确认。

## 5. IP、日志和设备信息

所有联网接收方会自然获得 IP 与基础请求信息。`installationId` 是 App 随机 UUID，不是硬件序列号。源码保留未调用的 `ANDROID_ID` helper，当前未发现上传路径。Release 不打印响应 body、Authorization、Cookie、token、密码、手机号、学号或成绩；Debug 仅允许已脱敏的 BASIC 元数据日志。

## 6. 保存、删除与撤回

- 设置 → 账号与数据管理：可清理学校绑定、学校会话/Cookie和本地学习数据。
- 自有账号中心：在后端可用时可退出、注销账号和删除预约资料。
- 用户可在系统设置撤销定位、相机、图片和通知权限。
- 反馈、投诉等部分服务端数据尚无用户自助删除接口：**待生产后端补齐或提供正式联系渠道**。
- 服务端法定保存期限、备份删除时点和注销后的日志处理：**待生产后端审计确认**。

## 7. 第三方与儿童/未成年人

第三方数据接收方见 `THIRD_PARTY_SDK_LIST_DRAFT.md`。当前未建立针对未成年人的独立处理流程；如正式面向未成年人或收集相关数据，必须在发布前补充监护人同意与最小化措施。

## 8. 联系方式与生效

正式运营主体、联系方式、发布日期、生效日期和政策在线 URL：**待生产基础设施与主体信息确定后补充**。不得用原项目网站或虚构域名代替。
