# 我的长理用户协议（发布前草案）

> 状态：DRAFT。争议处理、运营主体、联系方式、生效日期和正式 URL 待生产阶段补充。

## 1. 身份与服务性质

本应用由个人开发者独立开发，是面向校园生活场景的非官方辅助工具，与长沙理工大学不存在官方隶属或授权关系。应用不代表学校立场，也不保证学校或第三方系统持续可用。

## 2. 服务范围

当前功能包括本地课表/提醒、学校信息查询入口、自有账号、体育预约、失物招领、反馈和其他校园辅助工具。第一版不接真实支付，广告保持关闭。尚未部署生产服务的功能会显示“服务暂未开放”，不使用旧项目、测试或免费服务冒充生产服务。

## 3. 账号与学校凭据

- “我的长理”自有账号与学校教务账号相互独立。
- 用户只能使用本人有权使用的学校账号和资料，并应妥善保管密码。
- 学校凭据用于用户主动连接对应学校服务；当前可审计客户端逻辑不将其发送到自有后端。
- 本地依赖授权和最终成品网络行为仍需正式发布前复核。

## 4. 用户内容

用户不得发布违法、侵权、冒用身份、泄露他人隐私或与功能无关的敏感内容。失物招领图片和描述可能对其他用户公开，提交前应移除不必要的人脸、证件、联系方式和位置细节。

## 5. 外部服务

学校认证、教务、MOOC、校园卡、图书馆、四六级、普通话、高德地图及 GitHub 等由相应运营方提供。外部服务的可用性、账号规则和内容由其负责；App 会尽量标明外部页面和目标域名。

## 6. 账号与数据删除

用户可以退出或注销自有账号、删除预约资料、清理学校绑定和本地学习数据。具体可用性取决于生产后端；客户端不会把不存在的服务端删除能力表述为已完成。反馈、投诉等部分服务端数据删除能力仍待后端补齐。

## 7. 开源与知识产权

应用基于 CreaMakers 开源校园项目二次开发，保留 LICENSE、THIRD_PARTY_NOTICES 和上游 attribution。长沙理工大学校名、校徽和官方视觉不属于本项目开源许可；本项目不恢复或使用未授权校徽。

## 8. 草案限制

正式协议需在运营主体、生产域名、后端、安全措施和用户支持渠道确定后完成法律复核。本草案不构成对未知服务端保存期限、服务器位置、分发授权或外部服务可用性的承诺。
