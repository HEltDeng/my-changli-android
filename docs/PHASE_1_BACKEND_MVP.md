# 阶段 1：后端 MVP 本地联调

后端工程独立位于 `独立的本地后端工程目录`，不放入 Android 源码目录。它负责体育预约库存、失物招领、设备级测试身份，以及公告、版本、远程开关和反馈的管理基础数据。

## 启动与 USB 联调

1. 在后端目录执行 `python .\server.py`。
2. 对已连接的 Android 测试设备执行 `adb reverse tcp:8787 tcp:8787`。
3. 构建并安装 Debug APK。Debug 默认连接 `http://127.0.0.1:8787/api/v1/`。

如需修改 Debug 地址，仅在不纳入 Git 的根目录 `local.properties` 添加：

```properties
campusTools.apiBaseUrl.debug=http://127.0.0.1:8787/api/v1/
```

Release 默认使用不可解析的占位域名，避免误连本地或测试服务。正式部署时必须使用 HTTPS 并通过本地/CI 环境配置注入地址。

## 数据兼容

- 体育预约以服务端为准，最近一次成功结果会写入原 MMKV 存储供断网查看。
- 旧失物数据会以原本地 ID 作为 `clientLocalId` 幂等上传；服务端返回后继续使用原 ID 作为 App 内详情路由，避免覆盖安装后断链。
- 图片从 App 私有目录读取并上传到本地开发服务，单图限制 3MB；服务端图片文件保存在自己的 `uploads` 目录。
- 服务不可用时展示最近缓存，不会清空旧数据。

## 当前安全边界

- 当前支付仍为模拟确认，不调用微信、支付宝或银行卡。
- 当前没有预约码、扫码核验、退款或真实校方场馆库存。
- Debug 使用设备级测试身份；公网前必须升级正式账号认证、HTTPS、限流、审计、备份和密钥托管。
- 不应把数据库文件、管理员口令、会话令牌或上传图片提交到 Git。
