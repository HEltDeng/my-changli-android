## 分类说明

- A：发送至“我的长理”自有后端。
- B：直接发送给学校或其他外部服务。
- C：只在用户设备本地处理或缓存。

同一数据可能因不同功能进入不同分类，例如学号在教务查询时发送给学校，在体育预约核验时会发送给“我的长理”后端。隐私政策不得混写或笼统宣称所有学校数据都“仅本地”。
