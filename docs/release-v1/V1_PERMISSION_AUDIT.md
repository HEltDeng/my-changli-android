# V1 Release Permission Audit

- Date: 2026-08-12
- Evidence: final merged Release Manifest generated by `processReleaseManifest`

## Retained permissions

| Permission | OPEN consumer | Release decision |
| --- | --- | --- |
| `INTERNET` | Own Backend, announcements, flags, version metadata, lost-found, feedback, resource library, explicit public web pages | Keep |
| `ACCESS_NETWORK_STATE` | Network availability and failure-state handling | Keep |
| `POST_NOTIFICATIONS` | User-enabled class reminders | Keep; runtime request remains user initiated |
| `RECEIVE_BOOT_COMPLETED` | Re-schedule user-enabled local reminders/widgets after reboot | Keep |
| `SCHEDULE_EXACT_ALARM` | Exact local class reminders with fallback behavior | Keep; store declaration/manual policy review still required |

AndroidX adds an app-scoped `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`; this is a generated signature permission for non-exported dynamic receivers, not user data access.

## Removed or absent

| Permission class | Result | Reason |
| --- | --- | --- |
| coarse/fine location | Absent | Campus map is CLOSED |
| Wi-Fi state/change | Absent | No OPEN feature needs it |
| camera | Absent | System picker/content flow does not require a camera permission |
| media/images and legacy storage | Absent from merged Release Manifest | No broad storage access; debug-tool transitive legacy declarations are explicitly removed by manifest merger rule |
| foreground service | Absent | No V1 foreground service |
| boot-sensitive school/electric workers | Absent | Closed implementation removed |

## Export/deep-link result

Only `MainActivity` is exported as the launcher. Business activities, receivers and services are non-exported. No business `<data>` deep link exists, so CLOSED features cannot be reached through a URI route.

## Residual review item

`SCHEDULE_EXACT_ALARM` is justified by the OPEN local timetable reminder, but it remains a store-sensitive permission. Manual store-declaration review and device testing of exact/fallback scheduling are still required.
