# “我的长理”发布签名保管与恢复

“我的长理”的 Release 签名资产由项目所有者在仓库外离线保管，不进入源码、Git、构建日志或公开文档。Debug 构建继续使用 Android 开发签名，与未来 Release 更新链相互独立。

签名资产必须至少保留两份加密离线备份，并限制为项目所有者本人访问。密钥库、别名或密码任一丢失，都可能导致已安装正式版本无法通过原应用身份覆盖更新；恢复时不得通过聊天、工单、网盘公开链接或源码仓库传递。

Gradle 仅在构建者显式设置 `MY_CHANGLI_SIGNING_CONFIG`、且外部本地属性文件完整时启用 Release 签名。配置缺失时 Release 产物任务会停止并给出不含敏感值的提示；Debug 构建不受影响。

本文件不包含密钥路径、密码、别名、证书内容或指纹。
