# 我的长理本地正式版验收说明

## 身份边界

- App 启动后先恢复“我的长理”独立账号；未登录时只显示登录/注册页。
- 当前可用路线是手机号账号，校内身份认证只保留等待学校授权的入口和数据字段。
- 教务绑定只用于用户主动查询自己的课表、成绩、考试等信息，不作为体育预约或失物招领的登录凭据。
- “我的长理”会话令牌使用 Android Keystore 加密后保存在应用私有目录，密码不落盘。

## 本地联调

1. 启动 `后端项目的 start-admin.ps1`。
2. 确认后台地址为 `http://127.0.0.1:8787/admin/`。
3. USB 调试设备执行 `adb reverse tcp:8787 tcp:8787`。
4. 安装 Debug APK，使用仅限本地验收的测试手机号账号注册。

## 回归重点

- 未登录不能进入首页、服务、我的、体育预约或失物招领。
- 登录、退出、切换账号、冷启动和覆盖安装状态正确。
- 体育预约冲突、每日次数、取消次数、临近开场限制和后台解除限制均由服务端决定。
- 体育预约和失物招领维护时保留入口并显示说明，后台恢复开放后刷新生效。
- 反馈可在 App 提交并在后台流转处理状态。
- 切换“我的长理”账号不应清除或上传教务绑定凭据。

## 当前不具备

本地版本没有短信验证码、学校 SSO、真实支付、退款、预约码、扫码核验和公网服务。Release 候选包仅用于本地技术验证，不可公开分发。
